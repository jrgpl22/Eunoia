🌿 Eunoia — Mood Tracker App

Eunoia is an Android mood-tracking application designed to help users record their emotions, reflect on their daily experiences, and become more aware of their emotional well-being.

Developed using Android Studio, the application provides a simple and user-friendly way to track emotional patterns over time.
